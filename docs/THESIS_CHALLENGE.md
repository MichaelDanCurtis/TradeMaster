# Independent thesis challenge

Open **Research → Thesis challenge** and choose a completed research brief.
Run one separate Codex/Astra call over the exact original sources and claims.
This uses the existing Codex subscription adapter; no additional AI API key is needed.

Every overview, catalyst, bull/bear and cross-source claim is assessed exactly once.
The response identifies support, tension, missing support, or a proposition the packet
cannot test. It explains the evidence that could change each assessment and supplies
explicit falsification tests. Supported means supported within the limited packet,
not an independently verified investment thesis. Missing evidence is not a negative fact.

Original packet and receipt hashes, model identity, source dates, usage, validation
results and response are preserved. The original brief remains separate. Evidence
links open the source disclosure; the ZIP contains the review and original attachments.
Challenges share the existing single active brief slot, exact request idempotency,
deadlines, citation/quote limits, tool restrictions and no automatic retry behavior.
Adding this mode preserves the canonical identity of older ordinary brief requests.

The reviewer makes a new inference using the same model and evidence. It does not
collect a second independent dataset, refresh company facts, establish complete
filing coverage, or prove that cited interpretations are correct. Sources and target
claims are untrusted input, not model instructions. No trading interface is provided.
